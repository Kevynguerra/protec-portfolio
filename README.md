## 💻 Sobre o projeto

O **PROTEC** é um portfólio desenvolvido com foco em apresentar projetos de forma moderna, interativa e profissional.

O projeto foi criado utilizando tecnologias web fundamentais e também serviu como ambiente de aprendizado prático, permitindo trabalhar com estrutura de páginas, estilização, JavaScript, responsividade, animações e publicação utilizando GitHub Pages.
